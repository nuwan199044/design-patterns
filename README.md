# 🧠 Single Responsibility Principle – Java Example

This project demonstrates the **Single Responsibility Principle (SRP)**, one of the SOLID principles, using Java classes with focused responsibilities.

---

## 📘 What is SRP?

> A class should have only one reason to change — it should only have one responsibility.

In this example, each class is focused on doing **only one job**:

| Class               | Responsibility                                |
|--------------------|------------------------------------------------|
| `LoanService`       | Handles loan interest logic                   |
| `NotificationService` | Handles sending OTP notifications           |
| `PrintService`      | Handles printing passbook information         |
